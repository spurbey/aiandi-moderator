# AI Forum Comment Moderator

An automated forum comment moderation system built with Cloudflare Workers AI (`clef-flash` and `clef`). It classifies student forum posts into `acceptable`, `toxic`, or `spam`, generates visual HTML dashboards, and tracks model edge-cases through human audits.

## File Overview

- `classify.py`: Python classification script that calls Cloudflare Clef API and generates HTML reports.
- `comments.json`: Primary dataset with 100 course forum comments.
- `comments-v2.json`: Second dataset with 100 complex and borderline comments.
- `results.html`: Moderation report generated by `clef-flash` on `comments.json`.
- `results-v2.html`: Moderation report generated by `clef` on `comments-v2.json`.
- `MISTAKES.md`: Manual audit documenting classification errors made by `clef-flash`.
- `MISTAKES-v2.md`: Manual audit documenting subtle edge cases and errors made by `clef`.
- `NOTES.md`: Summary of tools/models used and personal reflections on AI moderation limitations.
- `cloud-flare.sh`: Template showing required Cloudflare environment variables.
- `cloud-flare.local.sh`: Local credentials file containing API keys (ignored by git).
- `CLEF_API.md`: Documentation and reference for Cloudflare Clef API.

## Setup

1. Copy the credentials template to `cloud-flare.local.sh`:
   ```bash
   cp cloud-flare.sh cloud-flare.local.sh
   ```
2. Add your Cloudflare Account ID and Workers AI API Token in `cloud-flare.local.sh`:
   ```bash
   export CLOUDFLARE_ACCOUNT_ID="your-account-id"
   export CLOUDFLARE_API_TOKEN="your-api-token"
   ```

No external packages needed (uses Python standard library only).

## How to Run

### 1. Run on comments.json (clef-flash)
```bash
python classify.py
```
Generates `results.html`.

### 2. Run on comments-v2.json (clef)
```bash
python classify.py comments-v2.json clef results-v2.html
```
Generates `results-v2.html`.

### 3. View Results
Open `results.html` or `results-v2.html` in any web browser.

## Models and Tools Used

- **Cloudflare Workers AI:** `@cf/cloudflare/clef-flash` and `@cf/cloudflare/clef` decision models.
- **Python 3 Standard Library:** `urllib.request`, `json`, `re`, `os`, `sys`, `time`.
